# Wipegram v0.2.0

## Changes

- Scan and bulk-delete your own messages in supported Telegram Web K chats, including private chats, groups, forum topics and the main Saved Messages view.
- Review matches before deleting, with text, regex, date, message-type and topic filters, local reports and a privacy mode.
- Protect pinned messages by default, reject unverifiable authorship and invalidate previews when the target or account changes.
- Handle Telegram flood waits and transient failures with bounded retries, controlled batches and Stop support.
- Use the same runtime through a userscript or local Chromium and Firefox extensions with read-only popups.
- Render trusted templates through DOM creation APIs without runtime HTML parsing.
- Add maintenance, versioning and release guidance adapted from Wipecord, plus automated artifact and release-input checks.

## Install or update

Install the attached userscript in Tampermonkey or Violentmonkey, or use the [main install link](https://raw.githubusercontent.com/rafelolv/Wipegram/main/wipegram.user.js), which follows future development. Release attachments are fixed snapshots.

For extensions, follow the [local installation and update guide](https://github.com/rafelolv/Wipegram/blob/main/docs/EXTENSION.md). Requires Chromium 111+ or Firefox 142+. ZIPs are not signed Firefox XPIs or store releases; temporary Firefox installation ends on browser restart.

- Migration: no existing public Wipegram release requires migration. Enable only one Wipegram installation and reload Telegram Web K after installing or updating. Keep one cleanup running at a time.

- Passed on Node.js 24.22.2: locked dependency installation, unit tests, userscript and extension builds, metadata/syntax checks, runtime parity checks, ZIP/checksum verification and release-input validation. All 12 focused release-input tests passed.
