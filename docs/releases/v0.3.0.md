# Wipegram v0.3.0

## Changes

- Redesign the workspace with charcoal surfaces, green accents, separate filters and activity, and visible creator, version and proprietary license links.
- Keep the chat toolbar launcher and add a second floating Wipegram button above the composer; refresh icons, README artwork and previews.
- Keep your messages as the default scope. Add explicit, non-persisted admin mode for everyone's messages in groups and channels with verified deletion rights and typed confirmation for every admin deletion.
- Count only unique own messages as checked in normal mode; recheck ownership and admin permission before deletion retries.
- Prepare automatic Firefox submission after GitHub releases, including reviewer source, the current license, duplicate-version checks and listing character-limit validation.

## Downloads

- `wipegram.user.js`: userscript v0.3.0.
- `wipegram-chromium-0.3.0.zip`: unsigned local Chromium package.
- `wipegram-firefox-0.3.0.zip`: unsigned temporary Firefox package.
- `LICENSE`: copyright and permission notices.
- `SHA256SUMS`: SHA-256 checksums for all four files above.

## Install or update

Install the attached userscript in Tampermonkey or Violentmonkey, or use the [main install link](https://raw.githubusercontent.com/rafelolv/Wipegram/main/wipegram.user.js), which follows future development. Release attachments are fixed snapshots.

For local extensions, follow the [installation and update guide](https://github.com/rafelolv/Wipegram/blob/main/docs/EXTENSION.md). ZIPs are not signed Firefox XPIs or store releases. Enable only one Wipegram installation, reload Telegram Web K after updating and keep one cleanup running at a time.

- Migration: no manual data migration. Admin mode starts off and resets when the panel closes or the target, account or permission changes.

## Validation

- All 114 automated tests passed; reproducible userscript build, both extension packages, metadata, ZIP contents and SHA-256 checks passed.
- Userscript and installed Chromium extension browser checks passed with simulated Telegram data on Chromium 156.0.8078.4, including both launchers, responsive layout, own/admin scope, confirmation typing, cancellation and Stop.
- Mozilla web-ext 10.8.0 validation passed with no errors, notices or warnings.
- Real Telegram deletion and Firefox runtime were not tested. Firefox submission, signing, review and public store availability are separate; inspect the publication workflow for the actual submission state.

[Report issues](https://github.com/rafelolv/Wipegram/issues) with version, browser, installation method and reproduction steps. Omit credentials and private Telegram data.
