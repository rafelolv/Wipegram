# Wipegram v0.3.1

## Changes

- Fix slow Auto scans by checking one recent history page after sender search instead of walking an entire busy group; keep explicit full-history scanning available.
- Pace scan pages, preserve server cooldowns across Stop/rescan and disable hidden Web K retries so transient failures use bounded retries.
- Stop deletion after exhausted network/server retries instead of expanding failed requests across individual messages.
- Clear stale previews and confirmations when filters change; clear processed candidates after deletion while preserving the original report.
- Remove the redundant sidebar and settings shortcut, widen the workspace, show complete date fields and move regex into Advanced options.
- Fix unnecessary scrolling in the empty workspace and keep header controls accessible on narrow screens.

## Install or update

Install the attached userscript in Tampermonkey or Violentmonkey, or use the [main install link](https://raw.githubusercontent.com/rafelolv/Wipegram/main/wipegram.user.js), which follows future development. Release attachments are fixed snapshots.

For local extensions, follow the [installation and update guide](https://github.com/rafelolv/Wipegram/blob/main/docs/EXTENSION.md). ZIPs are not signed Firefox XPIs or store releases. Enable only one Wipegram installation, reload Telegram Web K after updating and keep one cleanup running at a time.

- Migration: no manual data migration. Admin mode starts off and resets when the panel closes or the target, account or permission changes.

## Validation

- All 122 automated tests passed; reproducible userscript build, both extension packages, metadata, ZIP contents and SHA-256 checks passed.
- Userscript and installed Chromium extension browser checks passed with simulated Telegram data on Chromium 156.0.8078.4, including both launchers, 320/380 px layouts, filter invalidation, report preservation, own/admin scope, confirmation typing, cancellation and Stop.
- Mozilla web-ext 10.8.0 validation passed with no errors, notices or warnings.
- Real Telegram deletion and Firefox runtime were not tested. Firefox submission, signing, review and public store availability are separate; inspect the publication workflow for the actual submission state.

[Report issues](https://github.com/rafelolv/Wipegram/issues) with version, browser, installation method and reproduction steps. Omit credentials and private Telegram data.
