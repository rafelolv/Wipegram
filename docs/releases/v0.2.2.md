# Wipegram v0.2.2

## Changes

- Keep confirmation typing inside Wipegram instead of leaking keystrokes to Telegram's composer, with contained focus, Tab navigation and Escape cancellation.
- Verify sender-search results against chat history in Auto mode so messages missing from search can still appear after cleanup or reload.
- Continue pagination past deleted-message placeholders and stop on incomplete or stalled history responses.
- Simplify the panel with neutral surfaces, optional date/pattern filters, a collapsed activity log and statistics shown when scanning begins.
- Restore the Stop button during running operations and apply privacy blur correctly inside Shadow DOM.
- Credit Rafael (rafaelolv) in userscript and extension metadata, add a local W icon and include explicit userscript update/install links.
- Introduce proprietary personal-use terms for original material distributed from 0.2.2 onward, preserving previously granted MIT permissions and third-party rights.
- Refresh the README with download buttons, current screenshots, the group/channel-discussion focus, native private-chat cleanup guidance and an Also check WIPECORD link.

## Install or update

Install the attached userscript in Tampermonkey or Violentmonkey, or use the [main install link](https://raw.githubusercontent.com/rafelolv/Wipegram/main/wipegram.user.js), which follows future development. Release attachments are fixed snapshots. Reload Telegram Web K after updating and enable only one Wipegram installation.

For extensions, follow the [local installation and update guide](https://github.com/rafelolv/Wipegram/blob/main/docs/EXTENSION.md). Requires Chromium 111+ or Firefox 142+. ZIPs are unsigned local packages, not store releases or signed Firefox XPIs. Firefox temporary installation ends on browser restart. Keep one cleanup running at a time.

- Migration: no settings migration is required. Review the [new license](https://github.com/rafelolv/Wipegram/blob/v0.2.2/LICENSE) before installing this version. Original covered material is for personal, non-commercial use; modification, redistribution and commercial use require prior written permission. Earlier MIT copies retain their original permissions.
- Auto now performs history verification after sender search unless the configured message cap is already reached. This can take longer in large chats. Explicit sender search remains available without verification.
- The primary focus is your own messages in groups, forum topics and channel discussion groups. Broadcast-channel posts remain unsupported. For clearing an entire private conversation, Telegram provides native deletion for both sides.
