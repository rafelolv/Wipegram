# Wipegram v0.4.0

## Changes

- Show actual deletion batches, elapsed time and live countdowns for Telegram rate limits and network retries.
- Add visible 100 / 500 / All scan presets, starting at 100, plus validated custom limits.
- Select or deselect individual results, browse every match in pages and confirm deletion of only the selected subset.
- Preserve selection across result pages and record selected IDs and flags alongside all scanned matches in reports.
- Start Skip pinned messages unchecked. Enable it to protect pins; confirmation explicitly states when pinned messages are included.

## Downloads

- `wipegram.user.js`: userscript v0.4.0.
- `wipegram-chromium-0.4.0.zip`: unsigned local Chromium package.
- `wipegram-firefox-0.4.0.zip`: unsigned temporary Firefox package.
- `LICENSE`: copyright and permission notices.
- `SHA256SUMS`: SHA-256 checksums for all four files above.

## Install or update

Install the attached userscript in Tampermonkey or Violentmonkey, or use the [main install link](https://raw.githubusercontent.com/rafelolv/Wipegram/main/wipegram.user.js), which follows future development. Release attachments are fixed snapshots.

For local extensions, follow the [installation and update guide](https://github.com/rafelolv/Wipegram/blob/main/docs/EXTENSION.md). ZIPs are not signed Firefox XPIs or store releases. Enable only one Wipegram installation, reload Telegram Web K after updating and keep one cleanup running at a time.

- Migration: no manual data migration. Scans now start with a 100-message cap and Skip pinned messages off. Choose All for unlimited matches, or enable pin protection before scanning. Admin mode still starts off. Typed DELETE is based on the selected count and remains mandatory for every admin deletion.

## Validation

- All 126 automated tests passed; reproducible userscript build, both extension packages, metadata, ZIP contents and SHA-256 checks passed.
- Userscript and installed Chromium extension browser checks passed with simulated Telegram data on Chromium 156.0.8078.4, including both launchers, 320/380 px layouts, quick limits, selection across 501 matches, deleting only the selected subset, batch/elapsed/countdown display, timer cleanup, report preservation, own/admin scope, confirmation typing, cancellation and Stop.
- Mozilla web-ext 10.8.0 validation passed with no errors, notices or warnings.
- Real Telegram deletion and Firefox runtime were not tested. Firefox submission, signing, review and public store availability are separate; inspect the publication workflow for the actual submission state.

[Report issues](https://github.com/rafelolv/Wipegram/issues) with version, browser, installation method and reproduction steps. Omit credentials and private Telegram data.
